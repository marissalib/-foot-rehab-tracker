FOOT REHAB TRACKER — CLEAN VERSION

Upload/replace index.html and manifest.webmanifest in your existing GitHub Pages repository.
There is intentionally NO service worker in this version.

Features:
- 2–3 sessions/day, with 1/day as the minimum
- Correct PT exercise order
- Per-exercise timers
- Optional ice/frozen-bottle final step
- Pain before/after at the end
- Session notes
- History & progress
- Export data backup as JSON
- Data stored locally in Chrome using localStorage

Your existing data uses the same "footRehab" localStorage key and should remain available in the same browser/site after the update.
