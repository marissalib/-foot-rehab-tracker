FOOT REHAB TRACKER

This is a standalone mobile web app/PWA.

Included:
- 2–3 sessions/day tracking, with a minimum of 1
- 8 exercises in the order from your PT sheet
- Per-exercise timers
- Optional ice/frozen-water-bottle final step
- Pain before/after
- Session notes
- Same-day session count
- Local persistence on the device

To use it as an iPhone Home Screen app:
1. Put these files on a web host that provides HTTPS (GitHub Pages is a simple option).
2. Open the site in Safari on your iPhone.
3. Use Share -> Add to Home Screen and choose the option to open as a web app if offered.

Your entries are stored locally in the browser on the device. Clearing the site's browser data can erase the stored history.
